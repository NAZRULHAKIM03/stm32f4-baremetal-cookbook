# 05: Hardware-in-the-Loop Signal Verification

## Objective
Visually capture and verify the physical electrical waveforms generated by custom bare-metal I2C and SPI drivers using a multi-channel USB logic analyzer. 

## Verification Methodology
Rather than assuming the code works based on software output, this module uses hardware-in-the-loop debugging to inspect clock polarity, framing, and data timing at the pin level:
* **I2C Verification:** Captures the 100 kHz Standard Mode clock pulses on **PB8 (SCL)** and packet data on **PB9 (SDA)** while querying the INA226 power monitor.
* **SPI Verification:** Captures the master clock on **PA5 (SCK)** and raw stream data on **PA7 (MOSI)** during the transmission of dummy byte `0xAA`.

## Hardware Setup Map
* **Logic Analyzer:** 8-Channel 24MHz USB Logic Analyzer
* **Channels Used:**
  * `CH0` $\rightarrow$ PA5 (SPI SCK)
  * `CH1` $\rightarrow$ PA7 (SPI MOSI)
  * `CH2` $\rightarrow$ PB8 (I2C SCL)
  * `CH3` $\rightarrow$ PB9 (I2C SDA)
  * `GND` $\rightarrow$ STM32 Common Ground Rail
